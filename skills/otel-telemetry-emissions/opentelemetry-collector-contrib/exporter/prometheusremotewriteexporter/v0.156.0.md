# Prometheus Remote Write Exporter

## Metrics

| Metric name | Type | Unit | Attributes | Notes |
|---|---|---|---|---|
| `otelcol_exporter_prometheusremotewrite_consumers` | Sum (non-monotonic) | `{consumer}` | `exporter`; `endpoint` | Development stability. Set once at exporter startup to the number of configured worker goroutines. Worker count is either `remote_write_queue.num_consumers`, or (if `exporter.prometheusremotewritexporter.EnableMultipleWorkers` feature gate is enabled) an internal default, and is overridden by `max_batch_request_parallelism` if set. |
| `otelcol_exporter_prometheusremotewrite_failed_translations` | Sum (monotonic) | `1` | `exporter`; `endpoint` | Development stability. Incremented each time the pmetric-to-Prometheus translation returns an error while batching metrics for export. |
| `otelcol_exporter_prometheusremotewrite_sent_batches` | Sum (monotonic) | `{batch}` | `exporter`; `endpoint` | Development stability. Incremented once per remote-write request batch sent, regardless of the outcome. |
| `otelcol_exporter_prometheusremotewrite_translated_time_series` | Sum (monotonic) | `1` | `exporter`; `endpoint` | Development stability. Incremented by the number of Prometheus time series produced by the OTel-to-Prometheus translation. |
| `otelcol_exporter_prometheusremotewrite_wal_bytes_read` | Sum (monotonic) | `By` | `exporter`; `endpoint` | Development stability. Only emitted when the `wal` config block is set (write-ahead log enabled). |
| `otelcol_exporter_prometheusremotewrite_wal_bytes_written` | Sum (monotonic) | `By` | `exporter`; `endpoint` | Development stability. Only emitted when the `wal` config block is set. |
| `otelcol_exporter_prometheusremotewrite_wal_lag` | Gauge | `1` | `exporter`; `endpoint` | Development stability. Only emitted when the `wal` config block is set. |
| `otelcol_exporter_prometheusremotewrite_wal_read_latency` | Histogram | `ms` | `exporter`; `endpoint` | Development stability. Only emitted when the `wal` config block is set. Bucket boundaries: 5, 10, 20, 50, 100, 200, 500, 1000, 2000, 5000. |
| `otelcol_exporter_prometheusremotewrite_wal_reads` | Sum (monotonic) | `1` | `exporter`; `endpoint` | Development stability. Only emitted when the `wal` config block is set. |
